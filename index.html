Date: 30 Aug 2026 | Role: Individual Developer

พัฒนาเว็บไซต์ Learning Portfolio หน้าเดียวด้วย HTML และ CSS พื้นฐาน เพื่อแนะนำตัวเองและรวบรวมชิ้นงานในการเรียน

Skills: HTML5 CSS3 Semantic HTML

What I did: พัฒนาเว็บไซต์หน้าเดียวเพื่อแนะนำตัวเองและแสดงผลงาน โดยจัดโครงสร้างไฟล์และวาง Layout ด้วย HTML/CSS

What I learned: ได้เรียนรู้โครงสร้าง Semantic HTML การใช้งาน CSS Selectors และการเชื่อมโยงไฟล์รูปภาพกับไฟล์สไตล์

Next step: ต้องการพัฒนาเว็บให้รองรับ Responsive Design บนมือถือ และนำ Bootstrap มาช่วยจัดโครงสร้างได้ง่ายขึ้น

Evidence: GitHub Repository
