What I Built

เว็บไซต์นี้เป็น Learning Portfolio หน้าเดียวครับ มีส่วนประกอบหลักๆ คือ แนะนำตัว (About Me), อธิบายงาน (What I Built), ขั้นตอนการทำ (How I Built It) และสิ่งที่ได้เรียนรู้ (Reflection)

เรื่อง Client / Server: ตอนเปิดเว็บดูในเครื่องตัวเอง มีเกิดขึ้นแค่ Client (เบราว์เซอร์) อย่างเดียวครับ เพราะเบราว์เซอร์ดึงไฟล์ในคอมเรามาแสดงผลตรงๆ ยังไม่มี Server เกิดขึ้น เพราะไม่ได้ส่งข้อมูลผ่านอินเทอร์เน็ตหรือ HTTP ครับ

How I Built It

งานนี้เริ่มจากการสร้างโครงสร้างโฟลเดอร์ตามที่อาจารย์กำหนดก่อน แล้วค่อยสร้างไฟล์ index.html และไฟล์ style.css แยกกัน จากนั้นก็ค่อยๆ พิมพ์แท็ก HTML ทีละส่วน แล้วลองเปิดดูผลบนเบราว์เซอร์ควบคู่ไปด้วยครับ

ขั้นตอนและเครื่องมือที่ใช้ทำ:

  • จัดโครงสร้างโฟลเดอร์แยกเก็บไฟล์ css และ media ให้เป็นระเบียบ
  • ใช้ Semantic HTML เช่น <header>, <main>, <section> และ <footer> ในการจัดหน้าเว็บ
  • แยกโค้ดตกแต่งสี ฟอนต์ และจัดเลย์เอาต์ไปไว้ที่ไฟล์ css/style.css
  • ค้นหาวิธีใช้แท็กต่าง ๆ จากสไลด์เรียนวิชา CS100 สไลด์การสอนรายวิชา CS100 และเว็บไซต์ MDN Web Docs

Reflection

ปัญหาที่พบและการแก้ไข: ตอนแรกเปิดหน้าเว็บแล้วรูปไม่ขึ้นและ CSS ไม่เปลี่ยนตามที่เขียนไว้ เพราะพิมพ์ path ของไฟล์ผิดและสับสนการอ้างอิงโฟลเดอร์ พอไปเปิดทบทวนเรื่อง Relative Path ในสไลด์ แล้วเช็กชื่อโฟลเดอร์ให้ตรงกัน เว็บก็แสดงผลได้ถูกต้องครับ

สิ่งที่เข้าใจเกี่ยวกับการพัฒนาเว็บมากขึ้น: ได้เห็นภาพชัดเจนขึ้นว่า HTML ใช้สำหรับวางโครงสร้างเนื้อหา ส่วน CSS มีหน้าที่แต่งหน้าตาให้สวยงาม และการเลือกใช้ Semantic HTML ช่วยให้คนอ่านโค้ดเข้าใจง่าย

สิ่งที่อยากปรับปรุงในอนาคต: อยากลองปรับแต่งสีสัน เปลี่ยนฟอนต์ และจัดระยะห่างข้อความให้ดูสวยงามขึ้นครับ เพราะตอนนี้เว็บยังดูเรียบๆ เป็นโทนสีพื้นฐานทั่วไปครับ
